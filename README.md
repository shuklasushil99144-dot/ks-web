# KS Web — static site (HTML + CSS + JS)

Open `index.html` in a browser, or upload the whole folder to any host (Hostinger public_html, Netlify, GitHub Pages).

- `css/style.css`  — original compiled Tailwind stylesheet from the project (do not edit by hand)
- `css/extra.css`  — small additions (mobile menu, dropdown, toast, scroll bar)
- `js/main.js`     — all interactions; set `CONFIG.inquiryEndpoint` at the top to receive real form submissions
- `images/`        — hero + work images, favicon
- Pages: index, about, services, services-<slug> (4), work, contact, privacy, terms
